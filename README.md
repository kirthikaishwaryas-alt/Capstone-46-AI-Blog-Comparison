# Capstone 46: AI Blog Series with Before-and-After Comparison

## Project Topic
**Online Safety and Digital Privacy for Students**

## Project Overview
This project compares a manually written blog with an AI-assisted blog on online safety and digital privacy for students. It explores how AI tools can support writing while highlighting the importance of human review, fact-checking, privacy, and responsible AI use.

## Objectives
- Create a blog without generative AI assistance.
- Create an AI-assisted version of the blog.
- Verify factual claims using reliable sources.
- Identify errors, unsupported claims, and privacy risks.
- Compare both versions and document the findings.
- Promote safe and responsible digital practices among students.

## Main Topics Covered
- Phishing, online scams, and suspicious links
- Cyberbullying and identity theft
- Password security and two-factor authentication
- Social media privacy and public Wi-Fi safety
- Privacy considerations when using AI tools
- Responsible digital citizenship

## Tools Used
- ChatGPT or Gemini
- Perplexity
- Grammarly
- Canva
- Google Docs, Forms, Sheets, and Slides
- GitHub

## Project Deliverables
The project includes planning documents, research sources, a manual blog, an AI-assisted blog, prompts, verification records, visual and social media content, automation materials, a presentation, and a final submission folder.

## Responsible AI Statement
AI assistance was used for outlining, drafting, and editing the AI-assisted blog. The content should be reviewed by the student, and factual claims and sources should be independently verified before submission.
